### commitune
a tool that turns a repo's github commit history to music

### what is this?
this is a website that turns your github repo into a tune!
just input your `author`/`repo`/`branch` and click run


### where can i use this?

you can go to [commitune](https://commitune.vercel.app/) to try it out!

**notice**: the github api is rate-limited, and this uses at least 12 calls per tune, so its limited to 5 tunes per hour
